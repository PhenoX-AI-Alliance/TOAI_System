5. 課題

  • レート制限と可用性：17:17 に 429、18:59 と 23:50 に 503 を計 4 回観測。リトライ（最大 5 回）で吸収したが、レイテンシ増とバジェット消費が発生している。
  • 404 Not Found の連続発生：23:50:42 に generativelanguage の chat/completions が 404、23:51 以降 openrouter も 3 回連続 404。エンドポイント URL もしくはモデル ID の不整合が強く疑われる。
  • Flaky Test の未モデル化：非決定論的エラーの発生確率が統計的にモデル化されておらず、環境隔離による再現性確保が前提作業として残っている。
  • 残タスクの不可視化：実行シーケンス終了ログに「残タスク: {len(new_pending)} 件」とリテラルが出力されており、残件の実数が監査できない。フォーマット文字列の展開漏れ。
  • メッセージ冪等性：同一 msg ファイルが 17:15 と 17:17 に二重受信。処理重複のリスクがある。
  • 静的解析制約の波及：全角英数字・空白の全面禁止がグローバル適用されており、日本語を含む生成物では表現制約が過度に厳しくなる懸念。
  • AI社員稼働メトリクスに対する過負荷シミュレーションが未実施で、組織運営ガバナンスの検証が滞っている。
